# AlexNet (Work in Progress)

Build just-in-time desktop apps without coding.

Turn ideas into working desktop tools in minutes — no code, no terminal. AlexNet wraps powerful AI CLIs (like Codex and Claude) in a simple, friendly app made for non‑technical users.

- Generate small “just‑in‑time” desktop utilities from plain instructions.
- Automate everyday tasks: organize files, draft docs, rename batches, and more.
- Interact with your computer safely through guided, reviewable actions.
- No coding: Describe what you want and click run.
- Private by design: Desktop app approach keeps control on your machine.

Who it’s for: creators, founders, ops, analysts, teachers — anyone who wants AI‑powered desktop helpers without learning complex AI tools.

This is an active WIP. We’re polishing the experience for non‑technical users.
